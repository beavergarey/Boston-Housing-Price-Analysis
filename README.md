# Boston-Housing-Price-Analysis
# Project Overview
This project involves analyzing housing price data in Boston to identify factors affecting property prices. We use various data science methodologies to uncover insights and build predictive models.
# Dataset Information
The dataset used is the Boston Housing Price dataset sourced from Kaggle
# CRISP-DM Process
The analysis follows the CRISP-DM (Cross-Industry Standard Process for Data Mining) methodology:
    Business Understanding: Identifying factors affecting Boston housing prices.
    Data Understanding: Exploratory Data Analysis (EDA), visualizations, and correlations.
    Data Preparation: Handling missing values, normalization, feature selection.
    Modeling: Applying regression models (Linear, Decision Tree, Random Forest, etc.).
    Evaluation: Evaluating model performance using metrics (R-squared, RMSE, MAE).
    Deployment: Presenting insights and actionable recommendations.
